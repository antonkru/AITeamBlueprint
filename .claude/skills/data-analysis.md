# Skill: Data Analysis

## Protocol
1. Describe the dataset: shape, columns, data types, null/missing values.
2. Identify key patterns, outliers, and trends.
3. State all assumptions made during analysis explicitly.
4. Produce actionable insights, not just observations.

## Output Format
- **Dataset Overview** — structure and quality summary
- **Key Findings** — bulleted list of patterns and insights
- **Visualisation Suggestions** — describe charts or tables that would best illustrate the findings
- **Recommended Next Steps** — concrete actions based on the analysis
