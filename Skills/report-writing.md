# Skill: Structured Report Writing

## Output Format
1. **Executive Summary** — 3-5 bullet points, key findings only
2. **Detailed Findings** — organised by sub-question or topic
3. **Confidence Notes** — flag anything uncertain or from a single source
4. **Sources** — numbered URL list with one-line description each

## Conventions
- Use markdown headings and bullet points throughout
- Quantify claims where possible (numbers, percentages, dates)
- Plain language — accessible without domain expertise
- Filename convention: `AgentOutbox/[type]-[topic]-[YYYY-MM-DD].md`
